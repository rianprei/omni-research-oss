# Provenance and distribution

The engine code, original research role instructions and icon bundled here are
parts of OmniResearch OSS. The original private v1.1.0 package also contained
three user-supplied Deep Research texts attributed by the user to Claude Code.
Their redistribution license was not provided or independently verified. The
texts have been **excluded** from this public-submission candidate. No third-party
research repository source code is vendored. Data providers remain independent
services with their own API policies, limits, terms and availability.

The project MIT license applies to the source distributed in this candidate.
It does not license third-party provider data or service names.
